# Lab 01 - A Tour of Google Cloud Hands-on Labs

## Lab Summary

In this lab, I was introduced to the basic concepts of cloud computing and learned how to navigate the Google Cloud Console. The focus was on understanding cloud infrastructure, creating a project, and exploring core services such as IAM and basic resource management.

## Lab Objective

The objective of this lab was to understand the fundamentals of cloud computing and get hands on experience with the Google Cloud Platform by creating a project, exploring the interface, and learning how cloud resources are managed.

## Tools & Services Used

- Google Cloud Platform (GCP) 
- Google Cloud Console IAM (Identity and Access Management)

## Steps Performed

1. Logged into Google Cloud Console using my account 
2. Created a new GCP project for the lab Navigated through the dashboard and explored available services 
3. Understood IAM roles and permissions structure 
4. Explored basic cloud services available in the console
