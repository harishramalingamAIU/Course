# Lab 2 - Getting Started with Cloud Shell and gcloud

## Lab Summary
This lab introduced Google Cloud Shell and the `gcloud` command line tool for interacting with Google Cloud resources. The lab focused on learning how to configure cloud environments, create and manage virtual machines, configure firewall rules, connect to compute resources using SSH, and view logs through command-line tools.

## Lab Objective
The objective of this lab was to gain hands on experience with Google Cloud Shell and the `gcloud` CLI by configuring a cloud environment, managing compute resources, practicing command-line operations, and understanding firewall and logging features in Google Cloud.

## Tools & Services Used
- Google Cloud Platform (GCP)
- Cloud Shell
- `gcloud` CLI
- Compute Engine
- Firewall Rules
- Logging Services
- Nginx Web Server
- SSH

## Key Steps Performed

### 1. Activated Cloud Shell
- Opened Cloud Shell from Google Cloud Console
- Authorized Cloud Shell access
- Verified account and project information

### 2. Practiced Basic gcloud Commands
- Checked authenticated accounts
- Viewed active project configuration
- Configured region and zone settings

### 3. Configured Environment Variables
- Stored Project ID and Zone using environment variables
- Verified values using terminal commands

### 4. Created a Virtual Machine
- Created a VM instance named `gcelab2`
- Configured machine type and deployment zone

### 5. Connected to the VM using SSH
- Connected securely to the VM instance
- Installed an Nginx web server on the VM

### 6. Updated Firewall Rules
- Added HTTP and HTTPS tags to the VM
- Created firewall rules to allow HTTP traffic

### 7. Tested Connectivity
- Verified communication with the VM using HTTP requests

### 8. Viewed Logs
- Listed available logs
- Filtered compute related logs
- Read logs related to the VM instance
